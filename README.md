# Simulador de Conta Bancária

Programa de console em Python que simula operações básicas de uma conta bancária,
com menu interativo e validação das entradas do usuário.

## Funcionalidades
- Consulta de saldo
- Depósito, com bloqueio de valores inválidos (letras, zero ou negativos)
- Saque, com bloqueio de valores inválidos e de saque acima do saldo
- Extrato com o histórico de movimentações

## Como executar
Requer Python 3.

python main.py

## Conceitos praticados
Funções, listas, variáveis globais, condicionais, f-strings e tratamento
de exceções (try/except).
